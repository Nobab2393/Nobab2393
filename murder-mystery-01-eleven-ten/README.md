# এগারোটা দশ — পার্ট ১/৩

**মার্ডার মিস্ট্রি · ২:১১.৬ · ১০৮০×১৯২০ · ২৪ fps · ইন্সপেক্টর আরিফের কণ্ঠ**

ধানমন্ডির পুরোনো বাড়ি, ঝড়ের রাত। শিল্পপতি মাহবুব খন্দকার স্টাডি রুমে মৃত: কপালে গুলি, ডান হাতে পিস্তল,
দরজা ভেতর থেকে বন্ধ, চাবি নিজের পকেটে। সবাই বলল আত্মহত্যা। কিন্তু তিনি বাঁ-হাতি — আর তাঁর ঘড়ি থেমেছে
**এগারোটা দশ**-এ, অথচ গুলির শব্দ শোনা গেছে **এগারোটা ত্রিশে**। মৃতের ফোনে একটা **পাঠানো না-হওয়া ভয়েস
মেসেজ**, প্রাপক: আরিফ।

## লুক — দুই স্তর

| | |
|---|---|
| **দৃশ্য** | ফ্ল্যাট ভেক্টর নয়ার — মোটা কালো আউটলাইন, এক রঙের ফিল, বর্ষার নেভি/অ্যাশ/অ্যাম্বার, গ্র্যাডিয়েন্ট নেই |
| **চরিত্র** | প্যাস্টেল ডসিয়ে কার্ড — ফ্ল্যাট ভেক্টর বাস্ট, প্যাস্টেল ব্যাকগ্রাউন্ড, নাম + পদ + নিজের বলা লাইন |

## ফাইল

| | |
|---|---|
| `01-script.md` | সন্দেহভাজনদের তালিকা, ১৮ শটের সময়, ১০টা লাইন |
| `minimax-prompts.md` | Hailuo-র ক্লিপ প্যাক |
| `lines.py` · `audio/scene01..10.mp3` | দশটা লাইন, এক কণ্ঠ |
| `plan.py` | ৩১৫৯ ফ্রেম (১৩১.৬ s); `SPLITS` — কার্ড আর ক্লু-শটের কাট |
| `film.py` | নয়ার গ্রেড, **কার্ড রেন্ডারার** (`cast_card`), ফোন UI, **ছায়া** (`behind`) |
| `mix.py` | বৃষ্টি, বজিদ, ভেজা জুতা, গাড়ির দরজা, দূরের গুলি, ঘড়ির টিক, নোটিফিকেশন, ফোনের স্পিকার |
| `cast/` | ৬টা বাস্ট (আরিফ, মাহবুব, শিরীন, কামাল, তানভীর, বদু) |
| `scene/` | বাড়ি, স্টাডি, ঘড়ি, বসার ঘর |

## চালানো

```bash
python3 plan.py && python3 film.py --crf 25 --out build/video.mp4
python3 mix.py      # -> murder-mystery-01-eleven-ten-1080x1920.mp4
python3 verify.py && python3 contact.py
```

## নোট

- কার্ডের প্যাস্টেল রং ছবির কোণা থেকে নেওয়া — প্রতিটা কার্ডের নিজের রং।
- শেষ ছায়াটা কোডে আঁকা (`behind()`): ব্লার করা কালো মাথা-কাঁধ, পেছনের বাতির রিম আলো — মুখ নেই।
- `deva.py`-তে `rm`/`cm` অ্যাঙ্কর যোগ করা হয়েছে (কার্ডের ডান-ঘেঁষা ইনডেক্সের জন্য)।
