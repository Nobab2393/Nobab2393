| শেডিং | **দুই টোন** — বেস + একটাই শ্যাডো রঙ, শ্যাডোর প্রান্ত ঝাপসা নয়, *একটু নরম* (১–২ px ফেদার); কোনো গ্র্যাডিয়েন্ট, কোনো এয়ারব্রাশ, কোনো স্পেকুলার হাইলাইট |
| রিম লাইট | আলোর দিকের বিপরীতে পিঠে সরু **উষ্ণ রিম** — চরিত্রটা ব্যাকগ্রাউন্ড থেকে আলাদা হয় |
| অনুপাত | বাস্তবের কাছাকাছি (৪–৫ মাথা লম্বা), কিন্তু হাত-পা একটু সরু-লম্বা, কাঁধ ঝুলে পড়া; মুখে **বড়, অর্ধ-ঢাকা চোখ** |
| মুখ | চোখের ভুরু আর চোখের কোণাই অভিনয় করে; মুখ সাধারণত **একটাই ভাব** ধরে রাখে — নির্লিপ্ত, বিরক্ত |
| শরীর | ফুল-বডি, থ্রি-কোয়ার্টার পোজ, ওজন এক পায়ে; হাতে গল্পের কোনো বস্তু (এখানে লাল কাপড়ে বাঁধা ফাইল) |
| ব্যাকগ্রাউন্ড | এক রঙের উষ্ণ ক্রিম (`#FDF6E4`), পায়ের নিচে **ফ্ল্যাট ডিম শ্যাডো** |
| টেক্সচার | হালকা কাগজের দানা অনুমোদিত (খুব কম); ভিনিয়েট বা ভারী গ্রেন নয় |

## প্যালেট (রেফারেন্স থেকে মাপা)

| ব্যবহার | হেক্স |
|---|---|
| লাইন / কালি | `#0B0B0C` (গাঢ়তম পিক্সেল `#000000`) |
| ব্যাকগ্রাউন্ড | `#FDF6E4` |
| শার্ট (হালকা) | `#E4D5B9` · শার্ট শ্যাডো `#C8BCAC` |
| প্যান্ট (হালকা) | `#676461` · প্যান্ট শ্যাডো `#4A443F` |
| ত্বক (হালকা) | `#C0895C` · ত্বক শ্যাডো `#8E5B3D` |
| লাল কাপড় | `#983935` · শ্যাডো `#7A2B28` |
| চুল | `#4A433D` (গোড়ায় `#382A23`) |
| চটি / চামড়া | `#382A23` |

**নিয়ম:** প্রতিটা বস্তুর জন্য **ঠিক দুটো** রঙ — বেস আর শ্যাডো। শ্যাডো বেসের চেয়ে ১০–২৫ %
গাঢ়, এবং রঙটা একটু ঠান্ডা/নিস্তেজ দিকে সরানো (মাপা উদাহরণ: শার্ট `E4D5B9`→`C8BCAC`,
ত্বক `C0895C`→`8E5B3D`)। তৃতীয় টোন লাগলে সেটা হাইলাইট নয়, বরং *গাঢ় কনট্যুরের* কাজ।

## ফিল্মে ব্যবহার করার সময়

- `film.py`-এ চরিত্র এখন `puppet.py` রিগ দিয়ে আঁকা হয় (ফ্ল্যাট ভেক্টর)। এই স্টাইলে যেতে হলে:
  বেস ফিল `LOOK` থেকে, শ্যাডো = বেস ১৫ % গাঢ় + ঠান্ডা দিকে সরানো, আউটলাইন `#0B0B0C` — তিনটাই যথেষ্ট, আলাদা রেন্ডার লাগে না।
- গ্রেড: উষ্ণ, হালকা লিফট (`×1.02 + 4`), ভিনিয়েট সর্বোচ্চ ৬ %, গ্রেন প্রায় শূন্য।
- রঙের হিসাব হাতে না করে `cel.py` থেকে নিন: `from cel import PALETTE, ramp, shade`।
  (`shade()` = ১৫ % গাঢ় + সামান্য ঠান্ডা — রেফারেন্সের মাপা শ্যাডোর কাছাকাছি, হুবহু নয়।)
- কার্ড/ক্যাপশন: কালো স্ট্রিপে নাম + ভূমিকা — এই অংশটা প্যাস্টেল যুগের কাঠামোই থাকবে।
