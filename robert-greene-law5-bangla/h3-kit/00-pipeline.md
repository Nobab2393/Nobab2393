# MiniMax H3-only production pipeline — Law 5 (বাংলা)

**উদ্দেশ্য:** ভিডিওর সব ভিজ্যুয়াল ও অ্যানিমেশন **শুধু MiniMax H3** দিয়ে হবে। এই ডকুমেন্টে সেই পুরো পাইপলাইন রেডি — চরিত্র শিট → Ref2VA ক্লিপ → অ্যাসেম্বলি।

## ⚠️ এই স্যান্ডবক্সে যা ব্লকড (পরীক্ষা করা)

| হোস্ট | ফল | মানে |
|---|---|---|
| `api.minimax.io` | HTTP 000 (fail) | H3 API কল করা যাবে না |
| `platform.minimax.io` | HTTP 000 | কনসোলও নয় |
| `api.minimaxi.com` | HTTP 000 | চীনা এন্ডপয়েন্টও বন্ধ |
| `huggingface.co` | HTTP 000 | H3 ওয়েটস ডাউনলোডও সম্ভব না |

এখান থেকে বাইরের নেটওয়ার্ক শুধু `github.com`, `codeload`, `api.github.com`, `pypi.org`, `npmjs.org`-এ খোলা। তাই H3 মডেল **এই পরিবেশে চালানো অসম্ভব** — MinMax-only ভিডিও বানাতে হলে আপনার নিজের MiniMax অ্যাকাউন্ট/API key লাগবে, আর ক্লিপগুলো আপনার দিক থেকে জেনারেট হয়ে এলে অ্যাসেম্বলি এখানেই (`03-assemble.sh`) করা যাবে।

## ধাপ ১ — চরিত্র শিট (MiniMax image / Nano-Banana ক্লাস মডেল)
`01-character-sheets.md`-এর ৫টি প্রম্পট চালান। প্রতিটি 4-view শিট (front / side / back / close-up), 9:16, ফ্ল্যাট ২ডি ভেক্টর স্টাইল। এগুলোই পরে `<Picture 1>` হিসেবে রেফারেন্স হবে।

## ধাপ ২ — ক্লিপ জেনারেশন (MiniMax H3, Ref2VA মোড)
`02-ref2va-shot-prompts.md`-এর ৬টি প্রম্পট, ক্রমে ৬টি ক্লিপ। সেটিংস:

| সেটিং | মান |
|---|---|
| Mode | **Ref2VA** (full reference) |
| References | চরিত্র শিট (`<Picture 1>`) — শট ৬-এ দুটি শিট নয়, একই `c5` |
| Aspect / resolution | **9:16, 1080×1920** |
| Duration | ৮ সেকেন্ড/ক্লিপ |
| Audio | **Off** (ন্যারেশন আমাদের বাংলা VO) — অথবা On করলে প্রম্পটে দেওয়া `<d>[Bangla]` লাইনই H3 বলবে |
| Seed | একই চরিত্রে একই seed রাখুন, কনসিস্টেন্সির জন্য |

## ধাপ ৩ — অ্যাসেম্বলি (এই রিপোতে রেডি)
```bash
bash 03-assemble.sh /path/to/h3-clips      # h3_01.mp4 … h3_06.mp4
```
স্ক্রিপ্ট: ক্লিপগুলো mute করে বাংলা VO (এই ফোল্ডারের `../audio/l1..l6.mp3`) বসায়, হালকা অ্যাম্বিয়েন্ট প্যাড মিক্স করে, ৯:১৬ ১০৮০p-তে ফাইনাল দেয়।

## কেন এই কাঠামো
- ন্যারেশন **off-screen voiceover** — তাই প্রম্পটে হুবহু "says in an off-screen voiceover … lips remain completely closed" লেখা, নইলে H3 চরিত্রের ঠোঁট নড়াতে চাইবে।
- প্রতিটি ক্লিপে **একটি করে চরিত্র** — H3-এ একাধিক চরিত্র এক ফ্রেমে রাখলে কনসিস্টেন্সি ভাঙে।
- `<d>[Bangla]`-তে লাইন **কপি-পেস্ট verbatim** — H3 গাইড বলে ডায়ালগ অনুবাদ/রিরাইট করা যাবে না।
