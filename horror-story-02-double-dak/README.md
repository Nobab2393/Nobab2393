# ভয়ের গল্প · পর্ব ২ — «দুইবার ডাক»

**২:০১.৭ · ১০৮০×১৯২০ · ২৪ fps · এক কণ্ঠ, বাংলা · ন্যারেশন · হরর**

সেই রাতের পরের সকাল: ঘরের মাটিতে দুটো হাতের ছাপ — রাফির নয়। ফজরের আজানের পর ওটা এক চিৎকার দিয়ে
মিলিয়ে যায়, আর সে শহরে ফিরে যায়। এক সপ্তাহ পর মেঝেতে পড়ে থাকা ফোনটা বেজে ওঠে; স্ক্রিনে নাম **«মা»** —
অথচ সিমটা সে নিজের হাতে ভেঙেছিল। ফোন থামে, আবার বাজে… আর এবার নামটা বদলে যায়।

> মা বলতেন, মানুষ ডাকে একবার… আর ওরা?

## ফাইল

| | |
|---|---|
| `01-script.md` | লগলাইন, চরিত্র, ১৬ শটের সময়, ১০টা সংলাপ, শব্দ |
| `minimax-prompts.md` | Hailuo-র ১৫ ক্লিপ: স্টিল + মোশন, in/out, নেগেটিভ, কন্টিনিউইটি |
| `lines.py` · `audio/scene01..10.mp3` | দশটা লাইন, পর্ব ১-এর একই কণ্ঠ |
| `plan.py` | টাইমলাইন → ২৯২০ ফ্রেম (১২১.৬৭ s); কণ্ঠ ১২ % টেম্পো, `build/sped/`-এ একবার রেন্ডার |
| `film.py` | রেন্ডার — অ্যাম্বার হরর গ্রেড, পাপেট, ফোনের স্ক্রিন কোডে আঁকা |
| `mix.py` | পাখি, বাতাস, ভেজা পা, হাত, আজান, চিৎকার, বাস, ফোনের রিং, দরজায় ঠক |
| `verify.py` · `contact.py` | সিঙ্ক যাচাই · বারো ফ্রেমের শিট |
| `cast/01-rafi-neutral.png` | রাফি (পর্ব ১-এর প্লেট) |
| `scene/bg-*.png` | ঘর (আলো/অন্ধকার), খোলা দরজা, ভেজা মেঝে, খাটের নিচ, পা, অবয়ব, ভোরের ছাপ, বাস, ফ্ল্যাট, শহরের দরজা |

## চালানো

```bash
python3 plan.py && python3 film.py --crf 25 --out build/video.mp4
python3 mix.py      # -> horror-story-02-double-dak-1080x1920.mp4
python3 verify.py && python3 contact.py
```

## নোট

- **কাট লাইনের ভেতরেও** আছে: লাইন ১০ তিন শটে ভাগ (ফ্ল্যাট → স্ক্রিন «মা» → স্ক্রিন «রাফি»),
  `plan.py`-এর `SPLITS`।
- ফোনের স্ক্রিন সেট প্লেট নয় — `film.py · phone_layer` কোডে আঁকে, তাই নাম বদল ফ্রেম-নিখুঁত।
- সেট প্লেটের সাদা বর্ডার ২% ক্রপ করা হয়েছে; অবয়বটা কখনো পুরো ফ্রেমে আসে না, মুখও দেখা যায় না।
