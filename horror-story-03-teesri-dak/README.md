# ভয়ের গল্প · পর্ব ৩ — «তৃতীয় ডাক» (ফাইনাল)

**২:১২.৬ · ১০৮০×১৯২০ · ২৪ fps · এক কণ্ঠ, বাংলা · ন্যারেশন · হরর**

ফোনের ওপাশে মা: সাত বছরের জ্বরে যে রাতটায় ওটা এসেছিল, মা রাফির হয়ে সাড়া দিয়েছিলেন — ত্রিশ বছর ধার।
এখন ধার শোধের সময়। ও তিনবার ডাকবে; দুবারে চুপ থাকতে হবে। তৃতীয়বারে…

> আপনার নাম কী?

## চালানো

```bash
python3 plan.py && python3 film.py --crf 25 --out build/video.mp4
python3 mix.py      # -> horror-story-03-teesri-dak-1080x1920.mp4
python3 verify.py && python3 contact.py
```

## নোট

- **এক কণ্ঠ, দুই তাপমাত্রা:** `PITCH = {s9: 0.935, s10: 0.925}` — `asetrate + aresample + atempo`
  দিয়ে পিচ নামানো, দৈর্ঘ্য একই। নতুন কণ্ঠ রেকর্ড করা হয়নি।
- `asetrate` ইনপুট ২৪ kHz-এ ভুল ফল দেয় — তাই চেইনের শুরুতে `aresample=48000` রাখা হয়েছে।
- লাইন ৮ («হ্যাঁ?») আলাদা ক্লিপ; তার আগে `EXTRA = {"s8": 1.8, "s9": 1.2}` — মোট ~২ সেকেন্ড ফাঁকা।
- কার্ডের ফিসফিস লাইন ১০-এর শেষ ২.৬ s-এর ধীর, নামানো, রিভার্বড কপি।
- আয়নার দুই প্লেট একই ফ্রেমে কাট করা — ক্রসফেড নয়; শেষ দুই শট একই প্লেটে ম্যাচ-কাট (z 1.10 → 1.30)।
