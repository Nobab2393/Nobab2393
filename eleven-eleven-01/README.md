## কীভাবে বানানো

```
python3 trim.py           # ক্লিপের মাথা-লেজের নীরবতা কাটে -> audio/trim/
python3 plan.py           # ন্যারেশনের সাইলেন্স মেপে কাট বসায় -> build/timeline.json
python3 film.py           # ২৮টা শট -> build/video.mp4   (--stills 12,40 দেখার জন্য)
python3 score.py          # ক্লক-টিক, রিং, পিয়ানো, ড্রোন -> build/mix.wav, তারপর মাক্স
python3 verify.py build/eleven-eleven-p1.mp4
python3 cast_sheet.py     # চরিত্রের শিট
```

- `lines.py` — দশটা বিটের স্ক্রিপ্ট (কণ্ঠ, কার্ড, কাস্ট)।
- `rig.py` — দুই-টোন সেল রিগ: হাত-পা-মাথা, IK দিয়ে "ফোন কানে" পোজ, ভুরু-চোখ-ঠোঁটে অভিনয়।
- `film.py` — প্লেট (৩৫ % বড় রাখা), ক্যামেরা, বৃষ্টি, কার্ড, ফোন-স্ক্রিন, গ্রেড।
- `score.py` — সব শব্দ সিন্থেসাইজড; কোনো স্টক লাইব্রেরি নেই।
- `scene/bg-*.png` — সেল-শেডেড নাইট প্লেট (`raw/`-এ অরিজিনাল)।

## সিঙ্ক

`plan.py` প্রতিটা ক্লিপ ডিকোড করে **আসল নীরবতা** খোঁজে, তারপর ১.০ সেকেন্ডের কম নয় এমন দূরত্বে
কাট বসায়। `trim.py` আগে ক্লিপের মাথার ২০০–৩০০ মিলিসেকেন্ড খালি জায়গা কেটে দেয়, তাই লাইন ঠিক
নির্ধারিত সময়েই শুরু হয়।

শেষ রিপোর্ট (`verify.py build/eleven-eleven-p1.mp4`):


গতির তারতম্য (ন্যারেশন, `plan.py`-তে): হুক আর ক্লিফহ্যাঙ্গার ১.৩০×, ভালোবাসার অংশ ১.১০–১.১৬×।

## স্টাইল

নতুন ডিফল্ট — [`../style-reference/STYLE.md`](../style-reference/STYLE.md) (2D cel-shaded)।
এই ফিল্মে সেটার সাথে রাতের ঠান্ডা নীল গ্রেড যোগ হয়েছে: ফ্ল্যাট বেস + এক শ্যাডো টোন + কালো
কনট্যুর, তার ওপর নীল শ্যাডো ও উষ্ণ অ্যাম্বার প্র্যাকটিক্যাল।

## কণ্ঠ

এক কণ্ঠ — আনিকা (voice-47)। রায়ান আর সাব্বিরের সংলাপও আনিকার মুখেই, উদ্ধৃতি হিসেবে;
স্ক্রিপ্ট যেভাবে চেয়েছে। শেষ লাইনের আগে **২ সেকেন্ড নীরবতা**, তারপর লাইন কাট + বিপ + কালো।
