## ভিতরে কী আছে

**Act 1 — 2D নীতিগুলো (0–3.4s).** একটা বল: anticipation (১.২৫×০.৭৫ স্কোয়াশ, ২২ ফ্রেম) →
launch-এ stretch (০.৮০×১.৩০) → আর্কে ওঠা (ease-out, বাঁকানো পথ) → apex-এ **moving hold**
(ঠ frozen নয়, ১০px শ্বাস) → মাধ্যাকর্ষণে পড়া (ease-in, `p²`) → impact স্কোয়াশ (১.৩০×০.৭০) →
**ড্যাম্পড স্প্রিং** follow-through, ৮ ফ্রেমে থামে।

**Act 2 — "THE SPLIT" (3.4–4.8s).** FAR / MID / FG — তিন স্তর Y-অক্ষে আলাদা হয় (far −১২০px, fg +১২০px),
চিপ দিয়ে নাম দেখানো হয়, তারপর আবার জোড়া লাগে। এই ১৫ ফ্রেমটাই ফরম্যাটের সবচেয়ে শেয়ারযোগ্য অংশ:
যে দর্শক স্তরগুলো আলাদা হতে দেখেছে, সে পরের পুশ-ইনকে **জুম নয়, গভীরতা** হিসেবে পড়ে।

**Act 3 — একটা ডলি, তিন গতি (4.8–10s).** `w = 1/z`; `s = 1 + 0.5w`, প্যান ৪০px।
far **১.০৫**, mid **১.০৯**, fg **১.১৪** — fg পার্শ্বে প্রায় ৩× দূরে সরে।

**Act 4 — স্ট্যাট চিপ (10–12s).** waterfall entry: নিচ থেকে, staggered ৩–৪ ফ্রেম, `power4.out`,
অপাসিটি বাইনারি (ফেড নয়)।

## যা সত্যি বলা দরকার

- **সব ভেক্টর, কোনো ছবি নেই** — স্তরগুলো কোডে আঁকা, তাই paint-out সমস্যা নেই; ফটো দিয়ে 2.5D করলে
  লুকানো অংশ রিপেইন্ট করা কাজের সবচেয়ে বড় ভাগ।
- **১০% ডলি** — এর বেশি হলে ফ্ল্যাট আর্ট শিয়ার করে (billboard distortion)।
- **Feather নেই, overscan আছে** — ভেক্টরে hard edge ঠিক, ফেদার ভুল দেখায়। প্রতিটি স্তর ফ্রেমের
  বাইরে পর্যন্ত আঁকা, তাই নড়ার সময় সিম ফাঁক হয় না।
- ফন্ট DejaVu (সিস্টেমে এটাই); আসল লুকে Inter Tight/Poppins ভালো।
