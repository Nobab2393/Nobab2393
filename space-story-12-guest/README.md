# স্পেস স্টোরি · পর্ব ১২ — «অতিথি»

**১:৫২.৫ · ১০৮০×১৯২০ · ২৪ fps · এক কণ্ঠ, বাংলা · সাসপেন্স**

মঙ্গল কলোনিতে রাত ২:১০। ভেতরের এয়ারলক নিজে থেকে খুলে যায় — বাইরের দরজা কেউ খোলেনি। মেঝের লাল
ধুলোয় তিন আঙুলের ছাপ। পাঁচজন ক্রু টর্চ আর রেঞ্চ নিয়ে নামে; গ্রিনহাউসের ট্যাংক থেকে ফোঁটা পড়ছে,
রোভার বে-তে একটা ছোট প্রাণী আটকা পড়ে, কমান্ডার চাপ কমানোর হুকুম দেন। তারপর উনিশ বছরের কমিউনিকেশন
টেক নোটবুক খুলে দেখে: পানি কমেছে, কিন্তু রিসাইক্লারের আউটপুট বেড়েছে। প্রাণীটা চোর ছিল না — প্রতি
রাতে ভাঙা রিসাইক্লার সারিয়ে যেত, পারিশ্রমিক এক মুঠো পানি। ভোরে সে কাচের ওপারে দাঁড়িয়ে পাঁচটা
টোকা দেয়: এক, দুই, তিন, চার, পাঁচ।

> আমরা ওকে খুঁজছিলাম। ও আমাদের গুনছিল।

## ফাইল

| | |
|---|---|
| `01-script.md` | লগলাইন, চরিত্র, ১২ শটের সময়, ১০টা সংলাপ, শব্দ, সিঙ্ক |
| `minimax-prompts.md` | Hailuo-র জন্য ১৪ ক্লিপ: স্টিল + মোশন প্রম্পট, in/out, কন্টিনিউইটি |
| `lines.py` | দশটা লাইন, এক জায়গায় |
| `audio/scene01..10.mp3` | এক কণ্ঠ, বাংলা |
| `plan.py` | টাইমলাইন — `python3 plan.py` দেখায় প্রতিটা শটের ফ্রেম |
| `film.py` | রেন্ডার — ক্যামেরা, পাপেট, গ্রেড, টেক্সচার |
| `mix.py` | শব্দ — ডোম, এয়ারলক, শক, মোটর, টোকা |
| `verify.py` | আসল mp4 মেপে সিঙ্ক যাচাই |
| `contact.py` | বারো ফ্রেমের কন্টাক্ট শিট |
| `cast/` | পাঁচ ক্রু + অতিথি, RNBA প্লেট |
| `scene/` | ছয়টা সেট: ডোম, এয়ারলক, মেঝে, গ্রিনহাউস, রোভার বে, ভোর |

## চালানো

```bash
python3 plan.py                       # timeline + frame counts
python3 film.py --stills 12,43,97     # look at a shot before the render
python3 film.py --crf 25 --out build/video.mp4
python3 mix.py                        # mix.wav + mux -> space-story-12-guest-1080x1920.mp4
python3 verify.py                     # frame count, drift, silence at cuts
python3 contact.py                    # twelve frames
```

## স্ট্যাটাস

- রেন্ডার: `build/video.mp4` (crf 25) → মিক্স → `space-story-12-guest-1080x1920.mp4`
- অডিও: `build/mix.wav` ১১২.৫০০ s · peak ০.৮৯ · rms −১৮.৪ dB
- কাট: ১২টার সবগুলোই লাইনের নিচের নীরবতায়

## নোট

- অতিথির প্লেটে অফ-রেজিস্টার ক্রিম আভা আঁকার ভেতরে থাকে, তাই `knock.py` flood-fill-এর পরে
  পাতলা ব্যান্ড erode করে বাদ দেয় — নইলে শরীরে ক্রিম পট্টি থেকে যায়।
- `film.py` এ্যালিয়েনকে সাধারণ ফিগার হিসেবেই দেখে (`06-guest`), শুধু আলাদা হাইট/ডিম।
