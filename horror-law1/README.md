> রবার্ট গ্রিনের *৪৮ Laws of Power* — আইন ১ (“Never Outshine the Master”) অবলম্বনে
> একটি মৌলিক বাংলা ভৌতিক উপকথা। এটি বইয়ের অনুবাদ বা উদ্ধৃতি নয় — ধারণার একটি গল্প-রূপান্তর।

## এক লাইনে

রোকেয়া আপার দোকানে “একটাই বাতি জ্বলে”। নতুন কর্মচারী মিঠু বেশি জ্বলে উঠল — আর তারপর
তার নামটাও কেউ মনে করতে পারল না।

**নীতিকথা:** যে আলো মনিবের আলোকে ছাপিয়ে যায়, সে আলো নেভানো হয়।

## নির্মাণ

```bash
python3 film.py --mix                      # কণ্ঠ + স্কোর → audio/mix.wav
python3 film.py --seg 0 900     /tmp/a.mp4 # ৩৩১৮ ফ্রেম, চার ভাগে
python3 film.py --seg 900 1800  /tmp/b.mp4
python3 film.py --seg 1800 2700 /tmp/c.mp4
python3 film.py --seg 2700 3318 /tmp/d.mp4
python3 film.py --join /tmp/a.mp4 /tmp/b.mp4 /tmp/c.mp4 /tmp/d.mp4
```

`--still 12.5` এক ফ্রেম দেয় (QA)। `OUT=` দিয়ে আউটপুট নাম বদলানো যায়।

### যা যা দিয়ে দৃশ্যটা দাঁড়িয়েছে

- **প্লেট + ক্যামেরা।** একটাই স্থির ইলাস্ট্রেশন, কিন্তু প্রতিটি দৃশ্যে আলাদা
  ক্রপ: ওয়াইড শট ফ্রেমে লেটারবক্স, ক্লোজ-আপ ফ্রেম ভরে দেয় — তাই শটের ছন্দ আছে।
  প্রতিটি মুভমেন্ট `sine_io` ইন/আউটে, উপরে হ্যান্ড-হেল্ড `wob()` জitter।
- **গ্রেড।** চারটি প্রিসেট numpy-তে একবার রেন্ডার হয় — `warm` (স্মৃতি), `cold`,
  `dark`, `ash` — দৃশ্য অনুযায়ী বদলায়, সঙ্গে দৃশ্যের ভেতরে ব্রাইটনেস র‍্যাম্প।
- **আলো।** বাতির গ্লো শুধু রাতের দৃশ্যে, `sin(lt*9.3)·sin(lt*2.7)` দিয়ে ফ্লিকার;
  রিভিলের মুহূর্তে ০.৭৫ সেকেন্ডের শেক + ফ্ল্যাশ (স্টিং)।
- **স্কোর।** সবটা numpy-তে সিন্থেসাইজড: ৪৩.৬৫ Hz ড্রোন + হুইস্পার-নয়েজ,
  লাইন ৪ থেকে হার্টবিট, রিভিলের ২.৬ সেকেন্ড আগে রাইজার, তিনটি স্টিং।
  কণ্ঠের নিচে Duck (৫৫%) টানা হয়, তাই কথা চাপা পড়ে না।
- **টাইপ।** বাংলা শেপিং `deva.py` (uharfbuzz + fontTools), ফন্ট Noto Sans Bengali।
  ক্যাপশন একবার রেন্ডার হয়ে ক্যাশ হয় — নইলে প্রতি ফ্রেমে ৪০ ms খরচ।
- **আলোর মিটার।** নিচের বারটাই গল্পের মাপকাঠি: ৪% → ১০০%। মিঠু যত জ্বলে,
  বার তত ভরে; ঠিক যখন ১০০% ছোঁয়, পর্দা কালো হয়ে আইনের কার্ড নামে।

### যেটা ভুল হয়েছিল (আর ঠিক করা হয়েছে)

1. **প্রথম লেআউটে ফ্রেমের ৪৫% খালি** পড়ে ছিল — প্যানেল ও টাইপ ছোট, নিচে শুধু ফুটার।
   প্যানেল বড় করা হলো (৫৪০ → ৬৭২, ওয়াইড/ক্লোজ ভাগ), টাইপ ৫৮ px, আর খালি জায়গা
   ভরে দিল স্ক্রিপ্ট-স্লাগ + আলোর মিটার।
2. **আইনের কার্ড ক্যাপশনের উপরে উঠে এসেছিল** — এখন কার্ডের আগে ০.৪৫ সেকেন্ডে
   পুরো ফ্রেম কালো হয়ে যায় (`veil`), তারপর টাইপ।
3. **প্রথম ক্লোজ-আপগুলো আধা-শট ছিল** (z≈2.0) — চেহারা ছোট। z≈2.9-এ তোলা হলো।
4. **`deva.text_image` প্রতি ফ্রেমে কল হচ্ছিল** → ২৯০ ms/ফ্রেম। ক্যাশ বসানোর পর
   **৪৫ ms/ফ্রেম** (৩৩১৮ ফ্রেম ≈ ২.৫ মিনিট রেন্ডার)।
