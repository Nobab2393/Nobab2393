## সৎ খোলাখুলি

- **অন-স্ক্রিন লেখা ইংরেজিতে** — এই স্যান্ডবক্সে বাংলা ফন্ট (Noto Sans Bengali) নেই, DejaVu ছাড়া
  কিছু নেই। বাংলা সবটা **কণ্ঠে** আছে। বাংলা টাইটেল চাইলে ফন্ট নামিয়ে দিলে দিতে পারব।
- **"Claude 2D animation style" = কোডে আঁকা** — প্রতি ফ্রেম `t`-এর ফাংশন, তাই রি-রেন্ডার করলে
  হুবহু একই ভিডিও আসে। ২৫২০ ফ্রেম, রেন্ডার সময় **৪ মিনিট ৩৯ সেকেন্ড**।
- **streets-realistic body movement নেই** — এটা ফ্ল্যাট ভেক্টর জ্যামিতি; চরিত্রগুলো ইচ্ছাকৃতভাবে
  জ্যামিতিক (বৃত্ত মাথা, রেক্ট্যাংগল শরীর), কারণ কোডে আঁকা মুখ অভিনয় ধরে না।
- অডিও টাইমলাইন: গলা ৬টি সেগমেন্টে, ১.৪ সে কোল্ড ওপেন + ০.৮ সে গ্যাপ + ৪.৬ সে এন্ড কার্ড।
