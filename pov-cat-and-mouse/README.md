# POV

**ফার্স্ট-পার্সন · ফটো-রিয়ালিস্টিক · ১:১৫ · ১০৮০×১৯২০ · ২৪ fps · কোনো ন্যারেশন নেই**

> আপনি বাড়িতে ঢুকছেন। বসার ঘর শান্ত, টেবিলে বিস্কুট রাখা। তারপর রান্নাঘরে কিছু পড়ে —
> আর ওই বাড়িতে তিনটে প্রাণী: আপনি, একটা ইঁদুর, আর একটা বিড়াল।

ক্যামেরাটাই আপনার চোখ। হাঁটার দোল, শ্বাস, কাঁধের মোচড়, হঠাৎ ঘুরে তাকানো — সব ক্যামেরাতেই
(এটা কোনো অ্যানিমেটেড POV নয়, একটা *ধরা-পড়া* ফুটেজের মতো), আর অডিও পুরোটাই ডাইজেটিক: পায়ের
শব্দ, ঘড়ির টিক, রান্নাঘরের ঠকঠক, ছোট থাবা, একটা চিঁঁ, তারপর সেই শব্দটা।

**গল্পের সাতটা বীট:** হলওয়ে → বসার ঘর → বিস্কুটের টেবিল → **রান্নাঘরে কিছু পড়ে** (whip pan) →
ময়দা আর থাপ্পড়ের ছাপ → মেঝেতে থাবা → টেবিলের নিচে → ইঁদুর ছুটে বেরোয় → **বিড়াল টেবিলের ওপর
দিয়ে লাফ** → সাদা ফ্ল্যাশ → উল্টোপাল্টা ঘর → বিড়াল নির্দোষ হয়ে বসে আছে, আর ইঁদুর জানালার কার্নিশে।

## ফাইল

| | |
|---|---|
| `plan_pov.py` | ১৪টা বীট, মোট ৭৫.০০ s · ১৮০০ ফ্রেম |
| `film_pov.py` | ক্যামেরা (walk/handheld/tilt/whip/crouch/track/shake/flash) + ফটোগ্রাফিক পাস (এক্সপোজার, ক্রোম্যাটিক ফ্রিঞ্জিং, ভিনিয়েট, গ্রেন, মোশন ব্লার) |
| `score.py` | পুরো সাউন্ড ডিজাইন সিন্থেসাইজ করা — ন্যারেশন নেই |
| `raw/` → `scene/` | ১০টা ফটো-রিয়ালিস্টিক প্লেট (একই বাড়ি) |
| `verify_pov.py` · `contact_pov.py` | যাচাই আর কন্টাক্ট শিট |

## চালানো

```bash
python3 plan_pov.py && python3 film_pov.py --crf 23
python3 score.py            # -> pov-cat-and-mouse-1080x1920.mp4
python3 verify_pov.py && python3 contact_pov.py
```

## নোট

- **কোনো ভয়েসওভার নেই** — ইচ্ছাকৃত। POV ফুটেজে নিজের গলা শোনালে "ধরা-পড়া" ভাবটা ভেঙে যায়;
  শ্বাস আর পায়ের শব্দই এখানে ন্যারেটর। চাইলে পরে এক কণ্ঠ যোগ করা যাবে।
- **একই বাড়ি:** দশটা প্লেট একই দেওয়াল (গাঢ় সবুজ/টিল), একই ওক মেঝে, একই জানালার আলোয় বানানো।
- **মোশন ব্লার** শুধু ওই দুই বীটে (whip pan, ইঁদুরের পিছু ধরা প্যান) — বাকি সব ফ্রেম ঝকঝকে।
- **অ্যানিমেশন নয়:** চরিত্রগুলো ফটো-রিয়ালিস্টিক; ধাওয়াটা ক্যামেরার গতিতে, আর ওই দুই প্রাণীর
  নিজের ছবিতে (থাবা, লাফ, ইঁদুর)।
