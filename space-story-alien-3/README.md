# স্পেস স্টোরি · অতিথি ৩

**১:৫০.৭ · ১০৮০×১৯২০ · ২৪ fps · এক কণ্ঠ, বাংলা · ন্যারেশন · সাসপেন্স**

তিন সপ্তাহ পরে ছোটটা বড় হয়েছে — এখন কোমরের সমান। প্রতি রাতে সে কাচে টোকা দেয়: পাঁচটা, তারপর একটা।
আজ রাতে একটা বেশি পড়ল — **ছয়**। জাহাজে পাঁচজন ক্রু, দুই অতিথি; তবু কে বাকি? তাপ-স্ক্যানে সাতটা নয়,
**আটটা** গরম দাগ। হোল্ডের পেছনের কোণে একটা কাঠের বাক্স — ম্যানিফেস্টে নেই, ছোঁয়া গরম, ভেতর থেকে
স্ক্রাবারের সুরে গুঞ্জন। অতিথি পথ আগলে দাঁড়ায়: বাক্স পাহারা নয়, বাক্সটা আটকে রাখা। ঢাকনা খুললে —
খড়ের মধ্যে কাচের জার, ভেজা লাল মঙ্গলের মাটি, আর মাটিতে একটা মুঠো, শ্বাস নিচ্ছে। লেবেলে তানিয়ার
নিজের হাতের লেখা। স্বীকারোক্তি ছোট: সে কলোনির স্টোর থেকে জারটা এনেছিল, জানত না কারা পিছু নেবে।

> আমরা ভাবছিলাম, ওরা আমাদের গুনছে। ওরা আসলে একটা পরিবার পাহারা দিচ্ছিল।

## ফাইল

| | |
|---|---|
| `01-script.md` | লগলাইন, চরিত্র, ১৪ শটের সময়, ১০টা সংলাপ, শব্দ, সিঙ্ক |
| `minimax-prompts.md` | Hailuo-র ১৪ ক্লিপ: স্টিল + মোশন প্রম্পট, in/out, কন্টিনিউইটি |
| `lines.py` · `audio/scene01..10.mp3` | দশটা লাইন, এক কণ্ঠ |
| `plan.py` | টাইমলাইন → ২৬৫৭ ফ্রেম |
| `film.py` | রেন্ডার (ক্যামেরা, পাপেট, গ্রেড, টেক্সচার) |
| `mix.py` | শব্দ: হাল, ডাক্ট, টর্চ, ঢাকনা, জার, গুঞ্জন, টোকা |
| `verify.py` · `contact.py` | সিঙ্ক যাচাই · বারো ফ্রেমের শিট |
| `cast/` | পাঁচ ক্রু + অতিথি (+ ছোটটা একই প্লেট, ছোট স্কেলে) |
| `scene/` | ব্রিজ, করিডর, ইঞ্জিন, কেবিন, জানালা, **হোল্ড**, **বাক্স** |

## চালানো

```bash
python3 plan.py
python3 film.py --stills 14,22,48,55,66,84
python3 film.py --crf 25 --out build/video.mp4
python3 mix.py            # -> space-story-alien-3-1080x1920.mp4
python3 verify.py && python3 contact.py
```

## নোট

- ছোট অতিথি আলাদা প্লেট নয় — একই `06-guest` প্লেট বড় স্কেলে (৭০০–৭৬০ px), তাই মুখ এক থাকে।
- `bg-crate.png` ইচ্ছাকৃতভাবে ক্লোজ-আপ: জার আর খড় ফ্রেমের বড় অংশ নেয়, ক্রু পেছনে দাঁড়ায়।
- টার্গেট ১১০.৭ s — কণ্ঠ ৯৪.৬৩ s, লিড ১০.৪৭ s, শেষ লাইনটা ১৫.৯৬ s (পুরো শট জুড়ে)।
