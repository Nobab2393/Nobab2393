# ভয়ের গল্প · পর্ব ১ — «ডাক»

**১:৪৭.৫ · ১০৮০×১৯২০ · ২৪ fps · এক কণ্ঠ, বাংলা · ন্যারেশন · হরর**

মা মারা যাওয়ার সাত দিন পর রাফি গ্রামের পুরোনো বাড়িতে একা ফেরে। রাত ঠিক দুইটায় দেয়ালের ঘড়িটা
থেমে যায় — তবু টিকটিক শোনা যায়। দরজার বাইরে থেকে মায়ের গলায় ডাক: «রাফি… খোকা… দরজা খোল।» হাত
খিলে যাওয়ার আগেই খাটের নিচ থেকে ফিসফিস: «খুলিস না, বাবা… ওটা আমি না।» — এই কণ্ঠটাও মায়ের। তারপর
বাইরের কণ্ঠটা আর মায়ের মতো থাকে না। আর শেষে: **দরজা কখনোই বন্ধ ছিল না।**

> আপনার দরজাটা… আপনি কি নিশ্চিত বন্ধ আছে?

## ফাইল

| | |
|---|---|
| `01-script.md` | লগলাইন, চরিত্র, ১৪ শটের সময়, ১০টা সংলাপ, শব্দ, সিঙ্ক |
| `minimax-prompts.md` | Hailuo-র ১৪ ক্লিপ: স্টিল + মোশন, in/out, কন্টিনিউইটি |
| `lines.py` · `audio/scene01..10.mp3` | দশটা লাইন, এক কণ্ঠ |
| `plan.py` | টাইমলাইন → ২৫৮০ ফ্রেম (১০৭.৫ s) |
| `film.py` | রেন্ডার — অ্যাম্বার হরর গ্রেড, পাপেট, টেক্সচার |
| `mix.py` | ঝিঁঝিঁ, বাতাস, হারিকেন, ঘড়ি, দরজা, ফিসফিস, হাসি, হৃদস্পন্দন |
| `verify.py` · `contact.py` | সিঙ্ক যাচাই · বারো ফ্রেমের শিট |
| `cast/01-rafi-neutral.png` | রাফি (RGBA প্লেট) |
| `scene/` | উঠান, বাড়ি, ঘর, দরজা, ঘড়ি, খাটের নিচ, খোলা দরজা |

## চালানো

```bash
python3 plan.py && python3 film.py --crf 25 --out build/video.mp4
python3 mix.py      # -> horror-story-01-dak-1080x1920.mp4
python3 verify.py && python3 contact.py
```

## নোট

- ১৯৭০-এর কমিক লুকে আলফা কাটার সময় **হ্যালো-erode বন্ধ** রাখতে হয় (`knock.py ... --no-halo`),
  নইলে ক্রিম শার্টে ছোট ছোট ছিদ্র পড়ে।
- সেট প্লেটের চারপাশে আঁকা সাদা বর্ডার ২% ক্রপ করা হয়েছে, নইলে ফ্রেমের কিনারে সাদা রেখা দেখা যায়।
- ঘড়ির টিক s5 (৪৬.৩ s) থেকে প্রতি সেকেন্ডে, ফিল্মের শেষ পর্যন্ত — থেমে যাওয়া ঘড়ির জন্য।
