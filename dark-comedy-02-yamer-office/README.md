# যমের অফিস

**ডার্ক কমেডি · ১:৫৮ · ১০৮০×১৯২০ · ২৪ fps · দুই কণ্ঠ**

> «আমি ত্রিশ বছর সরকারি অফিসে মানুষের ফাইল আটকে রেখেছি। মরার পর বুঝলাম, ওপরেও একই সিস্টেম।
> পার্থক্য একটাই — এবার আটকে আছে **আমার** ফাইল।»

হাবিব, ভূমি অফিসের সহকারী কেরানি। মারা গেলেন অফিসেই — হার্ট অ্যাটাক, কারণ লাঞ্চ ব্রেক বাতিল
হয়েছিল। যমপুরী কেন্দ্রীয় কার্যালয়ে গিয়ে শোনেন: ফাইল আছে, **সিল নেই**; সিল ম্যাডামের কাছে,
ম্যাডাম আজ মিটিংয়ে। কতক্ষণ? *«এই ধরুন... তিনশো বছর।»*

পুরোনো অভ্যাসে চা-পানির প্রস্তাব দিতেই কেরানির জবাব: *«এখানে ঘুষ নেওয়া হয় না, স্যার। এখানে
নেওয়া হয় শুধু **মিষ্টি খরচ**।»* পকেটে টাকা নেই — চল্লিশ বছরের জমানো সব দুনিয়াতেই; আছে শুধু
একটা মেয়াদোত্তীর্ণ গ্যাসের বিল। আর ফাইলে লেখা: তিনি জীবনে **এক লাখ তেতাল্লিশ হাজার ফাইল**
আটকে রেখেছেন।

তারপর কেরানি চশমা খোলেন। তিনি **করিম চাচা** — যাঁকে হাবিব বারো বছর আগে বলেছিলেন *«আজ হবে না,
কাল আসুন»*, আর যিনি এসেছিলেন তিনশো দিন। করিম চাচা হালকা হেসে বলেন: *«কেমন আছেন, স্যার?
আজ তো সময় হবে না। **কাল আসুন।**»*

আর যমপুরীতে কাল আসে না — এখানে সূর্য ওঠে না, শুধু **লোডশেডিং** হয়।

**ওপরে গিয়ে চা-পানি চলে না। আজই বেঁচে থেকে কাজটা করিয়ে নিন।**

## ফাইল

| | |
|---|---|
| `01-script.md` | সাতটা দৃশ্য, তেরোটা সেগমেন্ট, বিট-বাই-বিট |
| `minimax-prompts.md` | Hailuo-র ৩২ শট + চারটে কার্ড |
| `lines.py` | সেগমেন্টের টেক্সট, কে বলছে, কোথায় কত নীরবতা |
| `compose.py` | সেগমেন্টগুলো জোড়ে → `audio/scene01..07.mp3` (দুই কণ্ঠের লেভেল মিলিয়ে) |
| `audio/seg-*.mp3` | ১৩টা ক্লিপ — হাবিব `voice-45`, কেরানি `voice-46` |
| `plan.py` | ২৮৩২ ফ্রেম (১১৮.০০০ s); ৩০টা কাট |
| `film.py` | প্যাস্টেল গ্রেড, চারটে কার্ড, `flip` করা ক্যামেরা (একই কাউন্টার উল্টো দিক থেকে) |
| `puppet.py` | **চরিত্রের রিগ** — হাত, কাঁধ, মাথা, হাঁটার সাইকেল; ২৩টা শটে অভিনয় |
| `mix.py` | ফ্যান, মনিটরের বিপ, ফাইল, স্ট্যাম্প, ঘণ্টা, লোডশেডিং, ব্যাঞ্জো |
| `raw/` → `scene/`, `cast/` | ৭টা প্লেট · ৩টা বাস্ট |

## চালানো

```bash
python3 compose.py            # segments -> one file per scene
python3 plan.py && python3 film.py --crf 25
python3 mix.py                # -> dark-comedy-02-yamer-office-1080x1920.mp4
python3 verify.py && python3 contact.py
```

| | |
|---|---|

## নোট

- **অভিনয় এখন কোডে:** `puppet.py` একটা ছোট ভেক্টর রিগ — কাঁধ, কনুই, কোমর, মাথা; প্রতিটা শটে
  shot-relative keyframe দিয়ে পোজ লেখা। হাবিব ফাইল ঠেলে, বুক চেপে ধরেন (হার্ট অ্যাটাক), পকেট
  হাতড়ান, করিডোরে হাঁটেন; কেরানি ফাইল ঠেলে দেন, স্ট্যাম্প করেন, আর সিন ৬-এ চশমা খুলে ফেলেন —
  চশমা খোলার সঙ্গে সঙ্গে মুখটা নরম হয়ে যায়, আর কার্ডে নাম বদলে যায়।
- **কে কোথায় দাঁড়ায়:** কেরানি কাউন্টারের পেছনে, তাই তাঁর শটে কাউন্টারের নিচের অংশটা
  প্লেট থেকে আবার বসানো হয় (`occ`) — পা ঢেকে যায়। ক্রেতা সামনে, তাই তিনি কাউন্টার ঢেকে দেন।
  লাইন আর করিডোরে ভিড় প্লেটেই আঁকা; আমাদের চরিত্র ওদের সামনে।

- **দুই কণ্ঠ, একটা কৌতুক:** কেরানি আর করিম চাচা একই মানুষ, তাই কার্ডেও **একই ছবি** — শুধু নিচের
  লেখা বদলায়। চশমা খোলার আগে কেউ ধরতে পারে না।
- **একই সেট, আটটা কাট:** কাউন্টারে ফিল্মটা আটবার ফেরে, তাই প্লেটটা **উল্টো দিক থেকেও** শুট করা
  হয়েছে (`flip`) আর প্রতিটা কাট আলাদা জুমে — নইলে একই ছবি আটবার লাগত।
- **দুই কণ্ঠের লেভেল:** `compose.py` প্রতিটা সেগমেন্টের শুধু *শব্দময়* অংশের RMS দেখে −২১ dBFS-এ
  নামায়, নইলে কেরানি হাবিবের চেয়ে জোরে শোনাতেন।
- **সময়:** প্রথমে টেক্সট বড় হয়েছিল, পরে রিড ছোট আসে — গতি ১.২৯ থেকে ১.১৫-তে নামিয়ে ফিল্মটা
  ১:৫৮-এ আনা হয়েছে; ধীর গতিটা ব্যঙ্গের জন্য ভালোই লাগে।
