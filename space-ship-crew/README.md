# মঙ্গল ক্রু — জাহাজে

**একই পাঁচজন, নতুন পোশাক, নতুন জাহাজ।** মঙ্গল কলোনির ক্রু এখন একটা ছোট ডিপ-স্পেস জাহাজে — একই মুখ,
একই চরিত্র, শুধু কলোনির প্রেশার-স্যুটের বদলে জাহাজের কাজের পোশাক।

**লুক:** ১৯৭০-এর সায়েন্স-ফিকশন কমিক — মোটা কালো রেখা, চারটে ফ্ল্যাট রঙ (সরিষে, পোড়া কমলা, ক্রিম,
টিল), কঠিন কালো ছায়া, রঙের অফ-রেজিস্টার আভাস। প্লেটের মাঠ ফ্ল্যাট বালু-রঙা, ফ্রেম নেই।

## পাঁচজন

| # | | কাজ | জাহাজে যা বদলেছে |
|---|---|---|---|
| ০১ | রওশন আরা (৪৮) | জাহাজের কমান্ডার | টিল কভারঅল, কমলা কাঁধের প্যানেল, ক্রিম ফ্লাইট ভেস্ট, হাতে লগবুক |
| ০২ | হাবিবুল্লাহ (৩৫) | ইঞ্জিনিয়ার | সরিষে কভারঅল কোমরে বাঁধা, বুকে টুল-হারনেস, এক হাতে রেঞ্চ, হাতে দাগ |
| ০৩ | ডা. তানিয়া সুলতানা (৩১) | জাহাজের ডাক্তার | টিল কভারঅলের ওপর ক্রিম স্মোক, স্টেথোস্কোপ, স্টিলের মেডি-কিট |
| ০৪ | জুয়েল রানা (২৬) | পাইলট | হাড়-রঙা ফ্লাইট জ্যাকেট, কমলা হারনেস, চামড়ার ক্যাপ, গগলস ওপরে |
| ০৫ | শিশির চন্দ্র (১৯) | কমিউনিকেশন টেক | টিল কভারঅল, হাঁটুতে হলুদ ব্যান্ড, কাঁধে রেডিও প্যাক, হাতে নোটবুক |

## ফাইল

- `raw/0N-*-neutral.png` — মূল প্লেট (বালু-মাঠ, ফ্রেম ছাড়া)
- `cast/0N-*-neutral.png` — ট্রিম করা, মাঠ কাটা (RGBA), একই উচ্চতা
- `sheets/lineup.png` — পাঁচজন, এক স্কেলে, এক লাইনে
- `sheets/0N-*-card.png` — প্রতিটা চরিত্রের কার্ড, ৯০০×১২০০, নাম + কাজ + বয়স

```bash
python3 sheets.py     # cast/, lineup, পাঁচটা কার্ড
```

## নোট

`sheets.py` আগে প্লেটের চারপাশের আঁকা ফ্রেম খুঁজে কেটে ফেলে (`deframe`), তারপর মাঠের রঙ কর্নার থেকে
নিয়ে ট্রিম করে ও আলফা করে। কোনো প্লেটে ফ্রেম/প্যানেল আটকে গেলে সেটা নতুন করে আঁকাই সহজ — হাবিবের
দ্বিতীয় প্লেট তেমনই হয়েছিল।
