# স্পেস স্টোরি · অতিথি ২

**১:৪৭.০ · ১০৮০×১৯২০ · ২৪ fps · এক কণ্ঠ, বাংলা · সাসপেন্স · ন্যারেশন**

মঙ্গল ছেড়ে দশ দিন। ছোট জাহাজ, পাঁচজন ক্রু। পানির মিটারে প্রতি রাতে এক গ্লাস কমে, কেউ টের পায় না —
তারপর অক্সিজেন কমতে শুরু করে, দরজা সব বন্ধ থাকা সত্ত্বেও। মেঝের গ্রিল খুলে দেখা যায় করিডরের গর্তে
কিছু একটা আছে; ইঞ্জিন রুমের ভালভ হিসেব মিলিয়ে বাতাস সরাচ্ছে; স্ক্রাবার দুবার নিজেই চালু হয়েছে। রাতে
ডাক্তার দেখে — তিন আঙুলের হাত, তারপর দুটো বড় কালো চোখ। অতিথি পালায় না, শুধু একটা কাপড়ের পুঁটলি
বুকে চেপে বসে থাকে। পুঁটলি খুললে দেখা যায়: **ওরা দুইজন ছিল।** ছোটটা ঠান্ডা, নিঃশ্বাস নিচ্ছে না — বড়টা
দশ দিন নিজের বাতাস দিয়ে ওকে বাঁচিয়েছে। শেষে জানালার পাশে পাঁচটা টোকা, আর একটা ছোট টোকা।

> আমরা একজনের হিসেব রাখছিলাম। ও দুইজনের।

## ফাইল

| | |
|---|---|
| `01-script.md` | লগলাইন, চরিত্র, ১৪ শটের সময়, ১০টা সংলাপ, শব্দ, সিঙ্ক |
| `minimax-prompts.md` | Hailuo-র জন্য ১৪ ক্লিপ: স্টিল + মোশন প্রম্পট, in/out, কন্টিনিউইটি |
| `lines.py` | দশটা লাইন |
| `audio/scene01..10.mp3` | এক কণ্ঠ, বাংলা |
| `plan.py` | টাইমলাইন (`python3 plan.py` → ২৫৬৮ ফ্রেম) |
| `film.py` | রেন্ডার — ক্যামেরা, পাপেট, গ্রেড, টেক্সচার |
| `mix.py` | শব্দ — হাল, ডাক্ট, গ্রিল, ভালভ, স্ক্রাবার, টোকা |
| `verify.py` | আসল mp4 মেপে সিঙ্ক যাচাই |
| `contact.py` | বারো ফ্রেমের কন্টাক্ট শিট |
| `cast/` | পাঁচ ক্রু (জাহাজের পোশাক) + অতিথি + ছোট অতিথি |
| `scene/` | পাঁচটা সেট: ব্রিজ, করিডর, ইঞ্জিন, কেবিন, জানালা |

## চালানো

```bash
python3 plan.py
python3 film.py --stills 31,54,70,95
python3 film.py --crf 25 --out build/video.mp4
python3 mix.py            # mix.wav + mux -> space-story-alien-2-1080x1920.mp4
python3 verify.py
python3 contact.py
```

## নোট

- ছোট অতিথি আলাদা প্লেট নয় — একই `06-guest` প্লেট ছোট হাইটে (৪৩০–৫২০ px) বসানো, তাই মুখ এক।
- `plan.py`-এ টার্গেট ১০৭.০ s: কণ্ঠ ৯০.২১ s, লিড ১১.১৯ s — কোল্ড ওপেন ২টা শটে ভাগ করা।
- করিডরের গ্রিলের গর্তে অতিথিকে দাঁড় করানো হয়েছে যাতে মনে হয় সে গর্ত থেকেই উঠছে।
